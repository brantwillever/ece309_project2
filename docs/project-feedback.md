# My feedback on the project spec and difficulty

I think that the project spec was really well thought out! It provided me with the perfect mix of work that I still had to do, while also giving me a great starting point to work with. I think that all of the code that I had to write for this project was very reasonable. However, one area of difficulty I encounted was writing the test cases. I have never had any experience with writing test cases, so I think it was a useful thing for me to learn how to do this, but it did take me a very long time to figure out how to properly format and create the test cases to fit the project spec. I understand that this is a very important part of the design process, but I basically had to teach myself how to do this from scratch, since we have not really gone over this much in class, which was difficult for me. I tried to use AI as minimally as possible throughout this project, but I did have to use it a few times to validate and correct some code that I had written, especially with the test cases.
